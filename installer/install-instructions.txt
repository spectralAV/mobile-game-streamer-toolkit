===================================================================
               OBS scrcpy Source Plugin - Quick Start
===================================================================

Thank you for installing the OBS scrcpy Source Plugin!

All necessary runtime files and system drivers have been installed out of the box:
  - OBS scrcpy source plugin with hardware-accelerated FFmpeg decoding (D3D11VA)
  - scrcpy 4.1 runtime & ADB tools (installed to C:\Program Files\scrcpy\4.1)
  - Apple AirPlay 2 receiver runtime & iPhone USB Reverse Tethering helper
  - Apple Bonjour Service (mDNS discovery for AirPlay)
  - Apple Mobile Device Support + WHQL Apple USB/NCM & signed libusb0 drivers
  - Windows Defender Firewall inbound rules for OBS AirPlay & mDNS

1. How to set up Android (scrcpy Device Source - Requires USB Debugging):
   Step A - Prepare your Android phone (one-time setup):
   - Unlock hidden Developer options: open Settings -> About phone and tap
     "Build number" 7 times quickly (Xiaomi HyperOS/MIUI: tap "OS version" or
     "MIUI version"; OnePlus/OPPO/Realme: About device -> Version -> Version
     number; Samsung: About phone -> Software information -> Build number).
   - Samsung One UI 6+ note: if USB debugging is grayed out, go to Settings ->
     Security and privacy -> Auto Blocker and turn Auto Blocker OFF first.
   - Open Settings -> System (or Additional settings) -> Developer options and
     turn ON "USB debugging".
   - Connect your phone with a USB DATA cable (not a charge-only cable), keep
     the screen unlocked, check "Always allow from this computer", and tap
     "Allow" on the "Allow USB debugging?" popup.

   Step B - Add in OBS Studio:
   - Click '+' under Sources -> select "scrcpy Device Source".
   - Click "Refresh devices" and select your phone (default scrcpy path:
     C:\Program Files\scrcpy\4.1\scrcpy.exe).
   - Video and audio decode directly in OBS via GPU hardware acceleration
     (D3D11VA) without opening an external desktop window!

2. How to set up Apple iPhone / iPad / Mac (Apple AirPlay Source):
   Apple devices start streaming from the quick settings bar (Control Center):
   - In OBS Studio, click '+' under Sources -> "Apple AirPlay Source".
   - Check "Enable AirPlay receiver" (default name: "OBS AirPlay") and click OK.
   - Option A (Wireless 5 GHz Wi-Fi / LAN): connect your Apple device and PC to
     the same network (avoid Guest Wi-Fi).
   - Option B (Zero-Lag USB Cable): plug in your iPhone via USB cable, unlock
     the screen, tap "Trust" if prompted, and check "Enable iPhone USB Reverse
     Tethering" in the AirPlay source properties until USB Status is Active.
   - Start Screen Mirroring on your Apple device:
     * iPhone (Face ID) & iPad: swipe DOWN from the top-right corner of the
       screen to open Control Center (quick settings bar).
     * iPhone SE / Home-button models: swipe UP from the bottom edge.
     * Mac: click Control Center (two pill toggles) in the top-right menu bar.
     Tap the "Screen Mirroring" icon (two overlapping rectangles) and select
     "OBS AirPlay" (needed for both Wi-Fi and USB Reverse Tethering modes!).
   - When USB Reverse Tethering is unchecked or OBS is closed, your iPhone
     automatically uses 100% unmodified Apple USB drivers (Photos, File
     Explorer, iTunes, and Apple Devices work normally).

3. Low Latency Streaming Tips:
   - Audio buffer: set to 0 ms for lowest latency.
   - Video encoder: Leave on Auto or pick a hardware encoder
     (e.g., c2.google.avc.encoder or c2.qti.avc.encoder).
   - For AirPlay, ensure your PC and iOS device are on the same 5 GHz Wi-Fi.

To uninstall:
   Go to Windows Settings -> Apps -> Installed apps -> OBS scrcpy Source Plugin.
