# Roadmap To `1.0.0`

| Milestone | Focus | Status |
| --- | --- | --- |
| `0.3.x` | Native `scrcpy 4.1` read-only socket source, embedded Apple AirPlay 2 source, zero-config Windows installer with bundled Bonjour & Apple WHQL drivers, and session-only iPhone USB Reverse Tethering with full revert to stock Apple drivers | **Current (`v0.3.7`)** |
| `0.4.x` | Multi-iPhone selector for USB Reverse Tethering, per-source network interface binding for AirPlay, and automated recovery telemetry in OBS properties | Planned |
| `0.5.x` | Native zero-copy GPU texture path (`D3D11` shared texture import into `gs_texture_t`) for ultra-low CPU/PCIe overhead at 4K60 | Planned |
| `0.8.x` | Code-signed installer & helper binaries, automated end-to-end replay/loopback integration tests in CI | Planned |
| `1.0.0` | Stable production release with finalized plugin settings schema, multi-language locale pack, and clean-machine QA matrix across Windows 10 & Windows 11 | Planned |
